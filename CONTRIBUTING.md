# Contributing

Open an issue before changing public state or motion contracts. Keep decisions deterministic and hardware side effects outside this package. Add regression tests for boundaries and failures. For TypeScript run `npm run check`, `npm test`, and `npm run test:browser` when changing the panel. For Python run `uv lock --check`, `uv run ruff check src tests examples`, `uv run ruff format --check src tests examples`, `uv run pytest`, and `uv build` from `python/`. Keep observable behavior aligned across the two languages and include SDK versions in integration reports. Never commit credentials, raw audio, video, or identifying transcripts.
